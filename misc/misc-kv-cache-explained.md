# 输入 [100,200]，生成 3 个 token：每次 forward 算了什么

**设定：** 1 个头，`d=4`。  
**输入：** 第 0 个 token 的 embedding `x₀ = [100, 200]`。  
**再生成 3 个 token** → 一共 4 个位置（0、1、2、3）。  
`generate()` 每步把整段序列重新 `forward` 一遍。

每个位置 embedding 不同，投影后得到不同的 Q/K/V 行（数字和你 Flash Attention 例子里一样）：

| 位置 | embedding x | Q 行 | K 行 | V 行 |
|------|-------------|------|------|------|
| 0 | `[100, 200]` | `[1, 2, 3, 4]` | `[10, 30, 50, 70]` | `[50, 51, 52, 53]` |
| 1 | `[300, 400]` | `[5, 6, 7, 8]` | `[20, 40, 60, 80]` | `[54, 55, 56, 57]` |
| 2 | `[500, 600]` | `[9, 10, 11, 12]` | `[90, 110, 130, 150]` | `[58, 59, 60, 61]` |
| 3 | `[700, 800]` | `[13, 14, 15, 16]` | `[100, 120, 140, 160]` | `[62, 63, 64, 65]` |

因果：位置 `i` 只看键 `j ≤ i`。采样下一个 token 只看 **最后一行** 的注意力输出 `O[i]`。

---

## 四张完整表（位置 0–3 全在时）

```text
Q = │  1   2   3   4 │     K = │ 10  30  50  70 │     V = │ 50  51  52  53 │
    │  5   6   7   8 │         │ 20  40  60  80 │         │ 54  55  56  57 │
    │  9  10  11  12 │         │ 90 110 130 150 │         │ 58  59  60  61 │
    │ 13  14  15  16 │         │100 120 140 160 │         │ 62  63  64  65 │
```

---

## 第 1 次 forward：只有输入（长度 = 1）

**本次算了什么：**

| # | 算了啥 | 结果 |
|---|--------|------|
| 1 | `x₀=[100,200]` → `q_proj` → **Q[0]** | `[1,2,3,4]` |
| 2 | `x₀` → `k_proj` → **K[0]** | `[10,30,50,70]` |
| 3 | `x₀` → `v_proj` → **V[0]** | `[50,51,52,53]` |
| 4 | **S = Q · Kᵀ**，只有 `S[0,0]` | `1×10+2×30+3×50+4×70` = **500** |
| 5 | softmax 第 0 行 → **P[0,0]** | 只有一项 = **1** |
| 6 | **O[0] = P[0,0] × V[0]** | `[50,51,52,53]` |

矩阵形状：`Q` 1×4，`Kᵀ` 4×1，`S` 1×1，`V` 1×4。

```text
S[0,0] = Q[0] · K[0] = 500

O[0] = 1 × [50,51,52,53]
```

→ 采样得到第 1 个生成 token（embedding 将是 `[300,400]`）。

---

## 第 2 次 forward：输入 + 1 个生成 token（长度 = 2）

整段 `[t₀, t₁]` 重跑。**位置 0 的 Q/K/V 和第 1 次一模一样，但又算了一遍。**

**本次算了什么：**

| # | 算了啥 | 新算还是重复 |
|---|--------|--------------|
| 1 | **Q[0]** = `[1,2,3,4]` | **重复**（第 1 次就算过） |
| 2 | **K[0]** = `[10,30,50,70]` | **重复** |
| 3 | **V[0]** = `[50,51,52,53]` | **重复** |
| 4 | **Q[1]** = `[5,6,7,8]` | 新 |
| 5 | **K[1]** = `[20,40,60,80]` | 新 |
| 6 | **V[1]** = `[54,55,56,57]` | 新 |
| 7 | **S = Q · Kᵀ**，2×2 | 见下 |
| 8 | softmax **第 1 行**（用来采样） | 见下 |
| 9 | **O[1] = P[1,0]·V[0] + P[1,1]·V[1]** | 见下 |

**第 7 步 S 的四个数：**

```text
S[0,0] = Q[0]·K[0] = 500          （和第 1 次一样）
S[0,1] = Q[0]·K[1] = 1×20+2×40+3×60+4×80 = 700     （mask，位置 0 不用）
S[1,0] = Q[1]·K[0] = 5×10+6×30+7×50+8×70 = 1140   （mask）
S[1,1] = Q[1]·K[1] = 5×20+6×40+7×60+8×80 = 1400
```

**第 8–9 步（只看最后一行，采样用）：**

```text
可见：S[1,0]=1140, S[1,1]=1400

P[1,1] > P[1,0]  →  O[1] 主要 ≈ V[1] = [54,55,56,57]
```

→ 采样得到第 2 个生成 token（embedding `[500,600]`）。

---

## 第 3 次 forward：长度 = 3

**本次算了什么：**

| # | 算了啥 | 新算还是重复 |
|---|--------|--------------|
| 1–3 | **Q[0], K[0], V[0]** | **第 3 次重复** |
| 4–6 | **Q[1], K[1], V[1]** | **第 2 次重复** |
| 7–9 | **Q[2], K[2], V[2]** | 新 |
| 10 | **S = Q · Kᵀ**，3×3 | 见下 |
| 11 | softmax **第 2 行** | 见下 |
| 12 | **O[2] = P[2,0]·V[0] + P[2,1]·V[1] + P[2,2]·V[2]** | 见下 |

**第 10 步 S（位置 2 那一行用来采样）：**

```text
S[2,0] = Q[2]·K[0] = 9×10+10×30+11×50+12×70  = 1780
S[2,1] = Q[2]·K[1] = 9×20+10×40+11×60+12×80  = 2200
S[2,2] = Q[2]·K[2] = 9×90+10×110+11×130+12×150 = 5140   ← 最大
```

**第 12 步：**

```text
P[2,2] 最大  →  O[2] ≈ V[2] = [58,59,60,61]
```

→ 采样得到第 3 个生成 token（embedding `[700,800]`）。

---

## 第 4 次 forward：长度 = 4（3 个 token 都生成完）

**本次算了什么：**

| # | 算了啥 | 新算还是重复 |
|---|--------|--------------|
| 1–3 | **Q[0], K[0], V[0]** | **第 4 次重复** |
| 4–6 | **Q[1], K[1], V[1]** | **第 3 次重复** |
| 7–9 | **Q[2], K[2], V[2]** | **第 2 次重复** |
| 10–12 | **Q[3], K[3], V[3]** | 新 |
| 13 | **S = Q · Kᵀ**，4×4 | 见下 |
| 14 | softmax **第 3 行** | 见下 |
| 15 | **O[3] = P[3,0]·V[0] + … + P[3,3]·V[3]** | 见下 |

**第 13 步 S（位置 3 那一行）：**

```text
S[3,0] = Q[3]·K[0] = 13×10+14×30+15×50+16×70  = 2420
S[3,1] = Q[3]·K[1] = 13×20+14×40+15×60+16×80  = 3000
S[3,2] = Q[3]·K[2] = 13×90+14×110+15×130+16×150 = 7060
S[3,3] = Q[3]·K[3] = 13×100+14×120+15×140+16×160 = 7640   ← 最大
```

**第 15 步：**

```text
P[3,3] 最大  →  O[3] ≈ V[3] = [62,63,64,65]
```

---

## 一眼看清：K/V 每行被算了几次

| 行 | K | V | 第1次 | 第2次 | 第3次 | 第4次 | **总共** |
|----|---|---|-------|-------|-------|-------|----------|
| 0 | `[10,30,50,70]` | `[50,51,52,53]` | ✓ | ✓重复 | ✓重复 | ✓重复 | **4 次** |
| 1 | `[20,40,60,80]` | `[54,55,56,57]` | — | ✓ | ✓重复 | ✓重复 | **3 次** |
| 2 | `[90,110,130,150]` | `[58,59,60,61]` | — | — | ✓ | ✓重复 | **2 次** |
| 3 | `[100,120,140,160]` | `[62,63,64,65]` | — | — | — | ✓ | **1 次** |

**重复计算就在这儿：** 第 4 次 forward 时，真正新东西只有 **Q[3], K[3], V[3]** 和 **S 的第 3 行**；但 **K[0]、V[0] 被算了 4 遍**，K[1]、V[1] 算了 3 遍，K[2]、V[2] 算了 2 遍。

---

## 三步注意力公式（每次都一样，只是矩阵变长）

| 步 | 谁乘谁 | 第 2 次 forward 的例子 |
|----|--------|------------------------|
| ① | **Q · Kᵀ** → S | `S[1,1] = [5,6,7,8] · [20,40,60,80] = 1400` |
| ② | softmax → P | 对 `S[1,0], S[1,1]` 做（mask 后） |
| ③ | **P 的行 · V** → O | `O[1] = P[1,0]×[50,51,52,53] + P[1,1]×[54,55,56,57]` |

---

## 代码

`BasicsTransformerLM.generate()` 每一步 `self.forward(x)` 整段重算 → 就是上面第 1–4 次 forward。  
投影在 `model.py` 494–496 行：`Q = q_proj(x)`, `K = k_proj(x)`, `V = v_proj(x)`。
