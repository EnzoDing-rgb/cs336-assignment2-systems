grad_x 能不能也要 partial sum？

讲义做的事：把矩阵 X 的行切成两块，开 2 个 program。program 0 只管 X 行 0–1；program 1 只管 X 行 2–3。

grad_x[i,j] 只跟 X 的第 i 行有关 → 每个格子只有一个 program 会写 → 直接写进 grad_x，不要 partial。

grad_weight 要把所有行的贡献加起来 → 每个 program 只能加自己那几行 → 先写 partial_grad_weight，Python 里再 sum。

program_id =
grad_x：高亮 = 当前 program 写的行

第 1 步：手里有三张表（先别管 program）

  1. X：4 行 × 4 列。行号 i = 0,1,2,3，列号 j = 0,1,2,3。
  2. weight：2 行 × 4 列。
    • 第 0 行：10, 20, 30, 40
    • 第 1 行：50, 60, 70, 80
    下面用 weight[0,j] 表示第 0 行第 j 列，weight[1,j] 表示第 1 行第 j 列。
  3. y：4 行 × 2 列。为什么 2 列？因为 weight 有 2 行，X 的每一行要算 2 遍内积，得到 2 个数。
    • y 的第 0 列：用 weight 的第 0 行 和 X 的某一行相乘再相加
    • y 的第 1 列：用 weight 的第 1 行 和 X 的同一行相乘再相加

第 2 步：前向公式（以 X 的第 0 行为例，i = 0）

y[0, 第0列] = 1×10 + 2×20 + 3×30 + 4×40 = 300 y[0, 第1列] = 1×50 + 2×60 + 3×70 + 4×80 = 700

这里 x[0,0]=1 同时出现在两个式子里：第一个式子系数是 10（weight 第 0 行第 0 列），第二个式子系数是 50（weight 第 1 行第 0 列）。

第 3 步：反向时多了一张表 grad_output

grad_output 和 y 一样大：4 行 × 2 列。

  • grad_output[i, 0]：如果 y[i, 第0列] 增加 1，loss 增加多少（本例第 0 行是 100）
  • grad_output[i, 1]：如果 y[i, 第1列] 增加 1，loss 增加多少（本例第 0 行是 500）

第 4 步：grad_x[i,j] 怎么算（以 i=0, j=0 为例）

x[0,0] 只出现在 y[0, 第0列] 和 y[0, 第1列] 两个式子里，所以要加两项：

grad_x[0,0] = grad_output[0,0] × weight[0,0] + grad_output[0,1] × weight[1,0] = 100 × 10 + 500 × 50 = 1000 + 25000 = 26000

任意格子都是这个结构：

grad_x[i,j] = grad_output[i,0]×weight[0,j] + grad_output[i,1]×weight[1,j]

一共 两项。第一项只用 weight 第 0 行 + grad_output 第 0 列；第二项只用 weight 第 1 行 + grad_output 第 1 列。

第 5 步：假想——我们故意把两个 program 拆开算这两项

  • program 0：只算第一项 → 存入 partial_grad_x[0, i, j] = grad_output[i,0] × weight[0,j]
  • program 1：只算第二项 → 存入 partial_grad_x[1, i, j] = grad_output[i,1] × weight[1,j]

同一个 grad_x[i,j] 被两个 program 各写进缓冲区的一行，内核里仍不撞车（写 partial_grad_x[0,...] 和 partial_grad_x[1,...]）。

但要得到真正的 grad_x[i,j]，必须在 Python 里：

grad_x[i,j] = partial_grad_x[0,i,j] + partial_grad_x[1,i,j]

这就是「grad_x 也要 partial sum」的意思——不是因为行尾没对齐，是因为我们按 weight 的行把本来该加在一起的两项拆给了两个 program。

看哪一列 j：
固定 j = 0。左：program 0 只算 weight 第 0 行那一项；右：program 1 只算 weight 第 1 行那一项
partial_grad_x[0, i, j] = grad_output[i,0] × weight[0,j]
partial_grad_x[1, i, j] = grad_output[i,1] × weight[1,j]
相加后 = grad_x（整表）
