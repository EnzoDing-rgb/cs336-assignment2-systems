# 在线归一化：用 P=[1,2,3]、V=[4,5,6] 讲透

---

## 0. 第一性原理：注意力在算什么（读例子的前提）

这一节回答三件事：**P 是不是 Q×Kᵀ**、**P 与 V 结合后 O 是什么**、**公式里为什么要除以 P 的和**。

### 0.1 三个矩阵各管什么

固定**一个查询位置**（一行 Q）和**多个键位置**（多行 K、多行 V）：

| 矩阵 | 形状（直观） | 存的是什么 |
|------|----------------|------------|
| **Q** | 一个 d 维向量 | 当前位置「要查什么」 |
| **K** | 每个键一个 d 维向量 | 每个键位置「标的是什么」 |
| **V** | 每个键一个 d 维向量（或标量） | 每个键位置「实际带走什么数」 |

K 和 V 成对出现：同一个键下标 j，有一行 K[j] 和一行 V[j]。  
**K 只参与算「有多匹配」；V 只参与算「最后输出什么数」。**

### 0.2 S = Q×Kᵀ：分数，还不是 P

对每个键 j，算一个**标量分数**：

```text
S[j] = Q · K[j]   （两个 d 维向量的内积）
```

写成矩阵就是 **S = Q Kᵀ**（一行 Q，多行 K）。  
`S[j]` 大，表示当前查询与第 j 个键在 d 维空间里方向更一致、内积更大。

**S 是实数，可正可负，可大可小，行内各 j 之间没有「占比」约束。**

### 0.3 P 不是 Q×Kᵀ

**P 是 softmax 之后的权重**，由 S 变来，多两步：

```text
① 对每个 S[j] 取指数：  exp(S[j])
② 用整行 exp 之和除：  P[j] = exp(S[j]) / ( exp(S[0]) + exp(S[1]) + … )
```

因此：

- **P[j] ≥ 0**
- **一行里所有 P[j] 加起来 = 1**（每个 j 分到的是「比例」）

所以：**Q×Kᵀ 得到的是 S（分数）；P 是 S 经过 softmax 之后的权重。**  
若把 P 理解成 Q×Kᵀ，后面所有式子都会对不上。

### 0.4 P 与 V 结合：O 是什么

设一行权重 `P = [P₁, P₂, P₃]`，三个键的值 `V₁, V₂, V₃`（标量或向量同理）。

**定义：**

```text
O = P₁·V₁ + P₂·V₂ + P₃·V₃        （当 P₁+P₂+P₃ = 1 时）
```

**含义：** 输出 O 是三个值 V₁,V₂,V₃ 的**线性组合**；系数是 P₁,P₂,P₃。  
P₁ 大，O 在数值上更接近 V₁ 那一支；P₃ 大，更接近 V₃。  
在完整注意力里，每个查询位置各算一行 P、得到一个 O 向量；本教程用**标量 V** 把「组合」缩成一个好算的数字。

**O 不是又一个「匹配分数」**，而是：**按权重把各键上的 V 混成的一个结果**，作为该查询位置传给下一层的数据。

### 0.5 为什么文档里的 O 要除以 (P₁+P₂+P₃)

正文例子里的 `P = [1, 2, 3]` **故意没有先做 softmax**，三个数之和是 6，不等于 1。  
它们扮演的是 softmax **分子那一侧**的角色（正数、表示相对强弱，尚未归一成比例）。

此时加权平均要写成：

```text
         P₁·V₁ + P₂·V₂ + P₃·V₃
O   =   ─────────────────────────
              P₁ + P₂ + P₃
```

**分子**：按份量把各 Vᵢ 加起来。  
**分母**：把份量归一化，使结果等价于「比例 × 值」再求和。

**与 softmax 的同一回事：** 若令 `wⱼ = exp(Sⱼ)`，则

```text
O = ( w₁V₁ + w₂V₂ + w₃V₃ ) / ( w₁ + w₂ + w₃ )
```

右边每一项 `wⱼ/(w₁+w₂+w₃)` 就是 softmax 的 Pⱼ。  
**除以 P 的和，就是在做 softmax 里「除以整行 exp 之和」那一步**；只是例子用 1,2,3 代替了 exp(S)。

若 P 已是 softmax 结果（和为 1），公式退化为 `O = P₁V₁ + P₂V₂ + P₃V₃`，**不再单独除**。

### 0.6 整条链（对照后文例子）

```text
S  = Q·Kᵀ              分数（匹配强弱）
P  = softmax(S)        权重（和为 1 的比例）；例子用 [1,2,3] 表示未除总和前的正权重
O  = Σ Pⱼ Vⱼ / Σ Pⱼ   按权重混合各键的 V；和为 1 时就是 Σ Pⱼ Vⱼ
```

后文 **§1 起** 在 P、V 已给定的前提下，只讲 **O 如何分步算**（在线归一化）；**§6** 再接回 FlashAttention 按键块算 S、P、O。

## 1. 题目里有什么（在线归一化例）

### 行向量 P（权重）

```text
P = [ P₁, P₂, P₃ ] = [ 1, 2, 3 ]
```

`P` 是**三个正数**，表示三个键的相对份量（对应 softmax 分子一侧，**尚未除以 P₁+P₂+P₃**）。  
见 **§0.5**：除以和之后，才与「和为 1 的 softmax 权重」同一类对象。

### 列向量 V（要被加权的内容）

```text
      ┌   ┐
      │ 4 │  ← V₁
V  =  │ 5 │  ← V₂
      │ 6 │  ← V₃
      └   ┘
```

`V` 是**三个数竖着排**。第 `i` 个数记作 `Vᵢ`。  
在注意力里，`V` 是**值向量**：每个键携带的信息；输出要对这些值做加权平均。

### 标量 O（最终答案）

`O` 是**一个数**（本例只有一维 V；注意力里 `O` 常常是向量，道理相同）。

目标公式：

```text
         P₁·V₁ + P₂·V₂ + P₃·V₃
O   =   ─────────────────────────
              P₁ + P₂ + P₃
```

分子：每个份量乘上对应的 Vᵢ，再加起来。  
分母：三个份量相加，把结果归一成加权平均（见 **§0.5**）。

## 2. 一次算完（对照标准答案）

把数字代入：

**分子：**

```text
P₁·V₁ = 1 × 4 =  4
P₂·V₂ = 2 × 5 = 10
P₃·V₃ = 3 × 6 = 18
────────────────────
合计              32
```

**分母：**

```text
P₁ + P₂ + P₃ = 1 + 2 + 3 = 6
```

**O：**

```text
O = 32 / 6 = 16/3 ≈ 5.333…
```

下面用**在线**方式算，结果必须与 `16/3` **完全相同**（恒等变形，近似）。

---

## 3. 为什么要「在线」算

SRAM 很小，**不能一次把整行 P 和所有 V 都摊开算完再写结果**。  
做法是：**来一个 (Pᵢ, Vᵢ)，就更新一次当前的 O 和分母**，旧的贡献保留在 O 里，用分母的变化做重标定。

需要维护两样东西：

| 名字 | 含义 | 初值 |
|------|------|------|
| **分母（运行和）** | 目前已见过的 P 加起来 | 0 |
| **O（运行输出）** | 在**当前分母**下，已经算出的加权结果 | 0 |

每读入一对 `(Pᵢ, Vᵢ)`：

1. 分母加上 `Pᵢ`
2. 用**新的分母**，把旧的 O 和**新的一项** `Pᵢ·Vᵢ` 合并成一个新 O

合并公式（图中写法）：

```text
         O_旧 × 分母_旧  +  Pᵢ · Vᵢ
O_新  =  ─────────────────────────────
                  分母_新
```

其中 `分母_新 = 分母_旧 + Pᵢ`。

---

## 4. 三步手算（与图一致）

### 第 1 步：只看见 P₁=1，V₁=4

```text
分母_新 = 0 + P₁ = 0 + 1 = 1

O = ( O_旧 × 分母_旧 + P₁·V₁ ) / 分母_新
  = ( 0 × 0        + 1 × 4  ) / 1
  = 4 / 1
  = 4
```

此刻 SRAM 上记住：**分母 = 1，O = 4**。  
含义：若全世界只有第一个位置，权重全是 1，输出就是 `V₁=4`。

---

### 第 2 步：再看见 P₂=2，V₂=5

```text
分母_旧 = 1          （上一步留下的）
分母_新 = 1 + P₂ = 1 + 2 = 3

O = ( O_旧 × 分母_旧 + P₂·V₂ ) / 分母_新
  = ( 4 × 1        + 2 × 5  ) / 3
  = ( 4 + 10 ) / 3
  = 14/3
```

`4 × 1` 的含义：上一步的 O 是在分母为 1 时算的，分子其实是 `4×1=4`；现在分母变成 3，先把旧分子 `4` 保留，再加上新项 `2×5=10`，一起除以 3。

此刻记住：**分母 = 3，O = 14/3**。

---

### 第 3 步：再看见 P₃=3，V₃=6

```text
分母_旧 = 3
分母_新 = 3 + P₃ = 3 + 3 = 6

O = ( O_旧 × 分母_旧 + P₃·V₃ ) / 分母_新
  = ( (14/3) × 3    + 3 × 6  ) / 6
  = ( 14 + 18 ) / 6
  = 32 / 6
  = 16/3
```

`(14/3) × 3 = 14`：旧 O 乘旧分母，还原旧分子，再加 `P₃·V₃=18`，除以新分母 6。

**在线结果 O = 16/3，与第 2 节一次算完的结果相同。**

## 6. 与完整注意力公式的衔接

本例**直接给出** `P=[1,2,3]`，用来隔离「在线归一化」这一步。

完整注意力（**§0**）：

```text
S  = Q Kᵀ
P  = softmax(S)     每行 P 之和 = 1
O  = P V           矩阵乘：每行 P 对各键 V 做加权求和
```

当 P 已归一化时，`O = Σ Pⱼ Vⱼ`，**没有额外的除法**；本文分母 `P₁+P₂+P₃` 是在 P 尚未归一化时，把 softmax 的除法写进加权平均里。

FlashAttention 按键块算 S、在片上累加分母与 O，S 与 P 的整块矩阵留在 SRAM、不写回 HBM；合并逻辑与本文 **§3–§4** 相同。

## 7. 一张图记住数据流

```text
初值：分母=0，O=0

读 (P₁,V₁)=(1,4)  →  分母=1，  O=4
读 (P₂,V₂)=(2,5)  →  分母=3，  O=14/3
读 (P₃,V₃)=(3,6)  →  分母=6，  O=16/3   ← 写回 HBM（注意力里还有 L 等）

核对： (1·4 + 2·5 + 3·6) / (1+2+3) = 32/6 = 16/3  ✓
```

## 8. 总结

1. **S = QKᵀ** 是分数；**P = softmax(S)** 是和为 1 的权重；**P 等于 QKᵀ** 这一说法需要改成前两步。  
2. **O** 是按 P 把各键的 **V** 线性组合后的结果；标量例里就是加权平均。  
3. **除以 P₁+P₂+P₃** 在 P 未归一化时完成 softmax 的缩放；P 已和为 1 时，O = Σ PᵢVᵢ。  
4. **在线归一化**：每来一对 (Pᵢ,Vᵢ)，用分母重标定更新 O；与一次算完 **恒等**。  
5. FlashAttention 把「一个一个键」换成「一个键块一个键块」，数学仍是 **§3–§4**。
