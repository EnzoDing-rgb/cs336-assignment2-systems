Tensor Parallel FFN · 按 GPU 看形状

NTP=4。窄维 D=4（A B C D），宽维 DFF=4（E F G H）。本例每卡宽维块大小 = DFF/N = 1，所以 z、dz 等是 1×1 矩阵（不是「标量」——若 DFF=8 则同位置是 1×2 块）。 一切从 GPU 0 / 1 / 2 / 3 出发：图上画的就是该卡本地内存里的张量形状。
