FSDP + TP · 单层 FFN · 2×4 = 8 GPU

竖向 = TP（怎么算），2 行 · 横向 = FSDP（怎么存 + batch），4 列。 不用抽象的 i/j：记 TP 行 R0/R1、FSDP 列 C0–C3，卡名 R0C0 … R1C3。 小 FFN：D=4（窄维 A B C D），DFF=8（宽维 w0–w7），B=8（每列 batch=2）。

5 · 单卡故事：R0C2 一整层前向

  1. 常驻：W1 行 C 的 w0–w3 块 (1×4)，batch 2 条样本。
  2. All-Gather 横排：与 R0C0,R0C1,R0C3 拼出 W1⁽ᴿ⁰⁾ (4×4)。
  3. 算：x⁽ᶜ²⁾(2×4) · W1 → z · W3 → y_partial (2×4)。
  4. All-Reduce 竖排：与 R1C2 加 y → 完整 y⁽ᶜ²⁾。
  5. 反向：dy → 本地 dW → 竖 reduce dx → 横 scatter dW → 仍只存行 C 那块。
